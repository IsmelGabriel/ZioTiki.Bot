ℹ️ About Ziotiki Bot

Everything you need to know about the bot, its technology, and its purpose.

🤖

Ziotiki Bot

A multifunctional Discord bot combining moderation, entertainment, and generative artificial intelligence. Designed to enrich any server experience with helpful commands and natural conversations powered by OpenAI.

🟢 Active 🐍 Python 🧠 GPT-4.1-mini ⚡ discord.py
📋 General Information
  • 🤖 Name Ziotiki Bot
  • 🏷️ Commands Slash Commands (/)
  • 🧠 AI Model GPT-4.1-mini
  • 🗄️ Database PostgreSQL
  • 🌐 Web Framework Flask + Gunicorn
  • 🐍 Language Python 3
🧩 Modules (Cogs)
  • 🛡️ Admin Moderation
  • 🎉 Fun Entertainment
  • 📡 General Basic Utilities
  • 🧠 AI Artificial Intelligence
  • ⚠️ Command Error Error Handling
⚙️ Tecnologías utilizadas
🐍 Python 3 🤖 discord.py 🧠 OpenAI API 🗄️ PostgreSQL 🌐 Flask 🚀 Gunicorn / WSGI 🔐 python-dotenv 📦 psycopg2 🔁 asyncio 📝 logging
✨ Key Features
🧠

AI with Memory

The /ask command remembers your conversation history for contextual responses.

🔧

Per-Server Prompts

Every server can set its custom AI prompt using /setprompt, giving the AI a unique identity.

🛡️

Full Moderation

Mute, kick, and ban members with role hierarchy checks to prevent moderation abuse.

📊

Web Dashboard

Real-time control panel with live bot status, error logs, and prompt updates.

📖 User Manual

Complete guide to all available commands in Ziotiki Bot.

/

Slash Commands

All commands are executed using Discord Slash Commands by typing / followed by the command name.
Example: /ping  ·  /ask question: Hello, how are you?

Basic utilities available to all members

/ping
✅ No permissions needed General
🧠

Artificial Intelligence

Natural conversations powered by AI with contextual memory

💡 The AI remembers your conversation history per server. Use /reset to start fresh. 10-second cooldown per user.
/ask
Send a question or prompt to the AI. It remembers the context of previous messages with you in this server. Limit of 300 characters per message.
/ask <question>
✅ No permissions needed ⏱ Cooldown 10s
/reset
Clears all conversation history with the AI for your user in this server. Useful to switch topics or start a new conversation.
/reset
✅ No permissions needed
🌟 Tip: You can chat naturally. The AI remembers past interactions, so you do not need to repeat context in every message.

Moderation (Admin)

Tools for server moderators and administrators

⚠️ These commands enforce role hierarchy. You cannot moderate someone with a role equal to or higher than yours, the server owner, or the bot itself.
/mute
Mutes a server member. If the MemMuted role does not exist, the bot creates it automatically with appropriate channel permissions.
/mute <member>
🔒 Manage Roles
/unmute
Removes mute from a previously muted member.
/unmute <member>
🔒 Manage Roles
/kick
Kicks a member from the server. An optional reason can be attached.
/kick <member> [reason]
🔒 Kick Members
/ban
Permanently bans a member from the server. An optional reason can be attached.
/ban <member> [reason]
🔒 Ban Members
/setprompt
Configures a custom AI prompt for this server, defining the persona, tone, and guidelines for the AI.
/setprompt <new_prompt>
🔒 Administrator

Guide Conventions

How to interpret command syntax

  • <argument> Required argument. Must be provided.
  • [argument] Optional argument. Can be omitted.
  • 🔒 Indicates the minimum Discord permission required to run the command.
  • ⏱ The command has a cooldown between uses.
